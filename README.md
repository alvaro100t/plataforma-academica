## Descripción

La Plataforma Académica Básica es un proyecto académico desarrollado para practicar el uso de Git y GitHub mediante el trabajo colaborativo. El proyecto incluye archivos HTML, CSS y JavaScript para aplicar conceptos de control de versiones, ramas, commits, pull request y merge.

## Objetivo

Aplicar el flujo de trabajo colaborativo utilizando Git y GitHub para fortalecer las habilidades de desarrollo de software.
